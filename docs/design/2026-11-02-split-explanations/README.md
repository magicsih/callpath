# 코드 옆 구간 설명

사용자의 2026-11-02 변경 지시를 적용한다. 모든 줄에 설명하라는 의도가 아니며, 적당한 구간으로 묶고 반복되는 제목을 없애고 코드 옆으로 창을 분할한다. 기존 자동 생성, 전송 범위와 L3 개발 환경 검수 3회는 유지한다. [화면 기준](prototype.html), [테스트 계획](test-plan.json).

## 화면과 읽기

왼쪽 64%에 원본 코드, 오른쪽에 클래스 요약과 의미 단위 설명을 둔다. 경계는 드래그와 방향키로 조절한다. 설명 표시를 끄거나 LLM 설정이 꺼져 있으면 코드가 전체 폭을 쓴다. 설명이 도착해도 코드 줄 사이에 공간을 넣지 않으며 기존 줄 번호, 복사, diff, 투어 표시와 메모를 지킨다.

각 설명에는 제목을 반복하지 않고 본문과 실제 파일 줄 범위만 둔다. 조건 검사, 연속 계산, 외부 호출과 결과 처리, 상태 변경과 반환처럼 함께 읽는 구간을 설명한다. 보통 3~8줄을 묶고 짧은 메서드는 통째로 설명한다. 모든 줄에 하나씩 달거나 필드와 getter를 반복 설명하지 않는다. 클래스 요약은 첫 설명으로 두며 '클래스 설명' 제목도 반복하지 않는다.

코드와 설명은 각각 스크롤한다. 코드에서 보고 있는 구간을 오른쪽에서 강조하고, 줄 범위 버튼을 누르면 원본 편집기의 해당 구간으로 이동해 표시한다. 설명 본문은 선택과 복사가 가능하며 글을 선택하는 것만으로 코드를 이동시키지 않는다. 비교에서는 오른쪽의 이전 코드와 이후 코드 선택으로 시점을 구분한다. 지도 단계 설명은 그대로 유지한다.

## 상태와 데이터

작성 중에도 분할 폭을 유지한다. 숨기기는 요청 중단이나 설정 끄기와 구분한다. 오류, 중단과 빈 답에서도 코드는 유지하고 기존 상태와 다시 작성 동작을 제공한다. 큰 파일은 기존 제한된 범위와 대기열을 유지한다.

설명 응답은 source, line, endLine, class 또는 block, text를 사용한다. 양끝 줄을 검사하고 같은 소스의 본문 구간이 겹치거나 지나치게 잘게 나뉘면 거절한다. 프롬프트와 캐시 버전은 V2로 올려 기존 줄별 답을 재사용하지 않는다. 사용자 설정, 기록과 이전 캐시 파일은 삭제하지 않는다. 중첩된 요청 구간의 답은 최신 구간을 우선해 합친다.

기존 Monaco view zone 설명 코드는 새 옆 창으로 대체해 제거한다. 코드와 설명을 나누는 컴포넌트가 편집기의 스크롤과 줄 이동을 연결하고, 코드 편집기 모델은 바꾸지 않는다. 임시 호환 경로는 두지 않는다.

## 인수조건과 적용

의미 단위의 다중 줄 범위를 반환하는 실패 테스트부터 변경한다. 좌우 배치, 코드 줄 사이 설명과 반복 제목 없음, 폭 조절, 줄 이동과 강조, 시점 전환, 원본 파일과 코드 복사 불변, 자동 생성과 캐시, 중단과 오류, 좁은 창과 확대를 검수한다. 기존 전체 회귀와 독립 실행 검수 3회를 사용한다. 검수는 모의 LLM과 격리 데이터에서 진행하고 사용자 키체인이나 모바일 기기를 사용하지 않는다.

기존 Homebrew 배포 경로를 유지한다. 검증한 수정은 PR로 병합하고 0.1.1의 서명, 공증, 공개 다운로드와 cask 설치를 확인한다. 되돌릴 때는 코드 변경을 되돌려 새 버전으로 제공하며 사용자 데이터는 삭제하지 않는다.
